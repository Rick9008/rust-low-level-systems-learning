為什麼是 UnsafeCell<MaybeUninit<T>>

SPSC ring 的槽位型別是 Box<[UnsafeCell<MaybeUninit<T>>]>——不是抄來的巧合,是兩個正交問題逼出來的唯一合理型別。這頁把「兩層各解什麼、為何不能換 Cell、為何不用 Option」一次講死。ordering 側見姊妹頁 qa_atomic_ordering_rmw.html。

0 · 兩層正交:一層解「能不能改」、一層解「有沒有 T」

外層

UnsafeCell<…>

解 aliasing / 內部可變性:讓你能透過兩條 thread 共享的 &SpscRing 合法地改槽位。

內層

MaybeUninit<T>

解 初始化 / drop 生命週期:槽位一開始是空的,可能有、也可能沒有一個有效 T。

兩個問題你都有,所以兩層都要。合起來讀:「一格我能透過 & 改、而且可能有也可能沒有有效 T 的槽位」。

1 · UnsafeCell:唯一能「透過 & 改」的原始積木

Rust 別名模型:拿著 &T,編譯器就假設它不變(可 cache 進暫存器、重排、省略重讀)。把 &T 轉裸指標去寫一塊不在 UnsafeCell 裡的資料 → 立刻 UB。

UnsafeCell 是唯一告訴編譯器「這裡面即使透過 & 也可能被改,別做『不會變』假設」的標記。所有內部可變性型別(Cell / RefCell / Mutex / Atomic*)骨子裡都是它。

它不是 ptr——是包住 T 的結構,.get() 交給你 *mut T。它自己零同步:「兩條 thread 不會同時碰同一格」是你用 SP/SC 型別不變式 + head/tail 的 Release/Acquire fence 去證明的——這也是為什麼每個 unsafe 上面都要寫 SAFETY 不變式。

2 · 內部可變性階梯:安全包裝 = 標準庫打包好的證明

它們全部建在 UnsafeCell 上,差別在「誰幫你證明、代價、能不能跨 thread」。往上能用安全包裝就用;UnsafeCell 是階梯最底、專給「我在造新抽象、我當證明作者」。

型別誰證明安全代價Sync?用在
Cell<T>標準庫(單執行緒)零✗單 thread、整值換
RefCell<T>標準庫(執行期借用檢查,違反 panic)借用旗標✗單 thread、要真的 &/&mut
Mutex/RwLock<T>標準庫(上鎖)鎖 / 阻塞✓跨 thread、可接受鎖
Atomic*標準庫(lock-free)一個 word✓跨 thread、單字大小
UnsafeCell<T>你零(你扛證明)✗(自己 unsafe impl)上面都不合,你在造新抽象

ring 是怎麼被「逼」到 UnsafeCell 的:每層安全的都被刷掉——Cell/RefCell !Sync 出局 → Mutex/RwLock 要上鎖(否定 lock-free)→ Atomic* 只裝一個 word(裝不下任意 T)→ 全刷完只剩 UnsafeCell + 你自己的 fence 證明。你不是選它,是被逼下來的。

4 · MaybeUninit vs Option:Option 可用,但「高度錯」

MaybeUninit<T> 跟 T 同大小同對齊——它不是為了「更緊密」,是為了語意:合法持有「還不是有效 T」的記憶體(配置未初始化的 [T; N] 當場 UB),而且沒有解構子(永不自動 drop,讓你手控「首次寫不 drop 舊值 / pop 後不 double-drop / Drop 只清 [head,tail)」)。

Option<T> 其實能用、sound、甚至自動處理 Drop。但它是錯的高度,三個理由:

面向MaybeUninit<T>Option<T>
大小= T(MaybeUninit<u64> = 8B)常 > T,多 discriminant(Option<u64> = 16B)→ buffer 兩倍、cache 命中砍半
占用狀態由 head/tail 單一真相負責,槽位不帶 tagtag 是第二份、非 atomic 的占用旗標,抄一遍 head/tail 已知的事
讀取assume_init_read:無分支 move(初始化已由 [head,tail)+Acquire 證明)take() branch 檢查 tag(檢查已證明的事),或 unwrap_unchecked(同斷言卻仍付 tag 大小)
Option 不是錯,是高度錯:拿一個非 atomic 的 per-slot tag 去重新解決「這格占用了嗎」——但那件事你的 head/tail atomic 已經是單一真相來源。MaybeUninit 的立場:「占用與否由 index 全權負責;槽位只是一塊生的、對齊好的儲存空間,不帶 tag、不帶解構子。」

5 · 面試句庫

“UnsafeCell is the only primitive that lets you mutate through a shared & — every interior-mutability type is built on it. Unlike Cell, it has no safe mutation API, so every access is a marked unsafe block. That's exactly what a lock-free structure needs: the no-data-race invariant becomes something I prove at each site, not a convention I hope holds.” 把「為什麼不是 Cell」講到位。
“Both Cell and UnsafeCell are !Sync, so both need unsafe impl Sync. The difference is whether that promise holds: Cell exposes safe set/get that would race with no unsafe marker, so the impl would be unsound; UnsafeCell's only path is a raw pointer I control.” 秀你知道差別不在 !Sync。
“MaybeUninit is the same size as T and has no destructor — it lets the ring hold uninitialized slots and control drop manually. Option would work but pays a discriminant, duplicates the occupancy that head/tail already track, and forces a branch on a fact I've already proven.” 一句話說完 MaybeUninit vs Option。
