rust-low-level-systems-learning

互動教材

17 個模組,每個一頁。測試證明程式碼是對的,但建立不了直覺—— 這些頁面讓你親手把它弄壞,再看它為什麼壞。

怎麼用

每一頁的主體是一個可以操作的機制,不是一張圖。刻意把每個模組最容易錯的那一步做成按鈕: 把 Acquire 降成 Relaxed、把 while 換成 if、 ET 模式下只讀一半就停手、拔掉 generation tag——然後看它當場壞給你看。

順序建議跟著 stage 走(git log --oneline --reverse 就是這個順序), 但每頁都能獨立讀。程式碼在 reference/src/,設計取捨在 docs/*.md。

也可以直接跑

這些頁面是模擬器。真的要看它跑,repo 裡有四支可執行的 example——不加任何 dependency:

指令看什麼
cargo run -p reference --example loom_vs_stress 同一個 bug:壓力測試 2,000,000 次抓不到,loom 379µs 抓到
cargo run -p reference --example hw_bridge_server -- --evented 起一台 server,另開 terminal 用 client 打進去
cargo run -p reference --example hw_bridge_client -- drip 200 一次送一 byte,server 安靜等 800ms 才反應
cargo run -p reference --example tcp_echo_server 單執行緒 epoll,開幾個 nc 同時連,thread 數不會長
